\section*{Key Findings}
\begin{itemize}
  \item There is an existing market demand for software solutions in the tea industry.
  \item Tea factories are willing to adopt digital systems when they provide operational value.
  \item Falcon Tea Factory's current system only connects Tea Estate Owners and Factory Administration.
  \item Financial operations are managed through a separate software solution.
  \item There is an opportunity to develop a more comprehensive platform that integrates multiple stakeholders.
  \item The proposed system aims to connect:
  \begin{itemize}
    \item Tea Estate Owners
    \item Estate Managers
    \item Collecting Agents
    \item Receiving Agents
    \item Factory Administration
  \end{itemize}
\end{itemize}
