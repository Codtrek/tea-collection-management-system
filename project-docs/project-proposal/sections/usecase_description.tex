\usecase{Record Offline Collection Data and Synchronize}
{Record collection details and photographic evidence offline when no internet connection is available, with automatic synchronization once connectivity is restored.}
{Tea Collection Agent / Tea Estate Manager}
{Mobile application is installed; user is authenticated with a valid cached session.}
{1. The user records collection details and/or captures photographic evidence while offline.\newline
2. The system stores the data and photo files locally using SQLite and the device file system.\newline
3. The system marks each record with a pending sync status.\newline
4. Once connectivity is restored, the system detects the active connection.\newline
5. The system uploads pending records and photos to the backend and Cloudinary.\newline
6. The system updates each record's sync status upon successful upload.}
{Offline records are synchronized with the central database without data loss.}
{E1: Sync fails midway; the system retries automatically and preserves unsynced records locally.\newline
E2: Conflicting record detected during sync; the system flags the record for manual review rather than overwriting.}
