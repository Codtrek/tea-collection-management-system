\section{Requirements of the Project}
\label{sec:requirements}

\subsection{Functional Requirements}


\subsubsection{Tea Estate Owner Requirements}
\begin{itemize}
\item The system shall allow Tea Estate Owners to register employees.
    \item The system shall allow Tea Estate Owners to assign managers.
    \item The system shall allow Tea Estate Owners to view the status and performance of employees.
    \item The system shall allow Tea Estate Owners to view the total weight of tea leaves delivered to factories.
    \item The system shall allow Tea Estate Owners to view the estimated income generated from tea leaf collections.
    \item The system shall provide graphical reports and analytical insights related to tea leaf collections and income generation.
    \item The system shall provide graphical analytics related to individual employee performance.
    \item The system shall allow Tea Estate Owners to review and approve fertilizer requests submitted by managers.
    \item The system shall allow Tea Estate Owners to view the tea collection agents assigned to routes near their tea estates.
    \item The system shall allow Tea Estate Owners to submit tea leaf selling requests to the Factory after reviewing tea plucking completion reports submitted by Tea Estate Managers.
    \item The system shall allow Tea Estate Owners to submit fertilizer borrowing requests to Factory Officers.
    \item The system shall allow Tea Estate Owners to receive notifications regarding fertilizer request approvals or rejections from factories.
    \item The system shall allow Tea Estate Owners to track all tea leaf deliveries and monitor specific deliveries individually.
    \item The system shall allow Tea Estate Owners to receive complaint reports regarding tea leaf weight mismatches.
    \item The system shall allow Tea Estate Owners to submit complaints regarding fertilizer quality to Factory Managers.
\end{itemize}

\subsubsection{Tea Estate Manager Requirements}
\begin{itemize}
    \item The system shall allow managers to record daily tea plucking details of employees.
    \item The system shall allow managers to submit tea plucking completion reports to tea estate owners.
    \item The system shall enable managers to keep photographic evidence of the tea leaves collected by the Tea collection agent.
    \item The system shall allow managers to submit fertilizer requests to tea estate owners when fertilizer stock levels are low.
\end{itemize}

\subsubsection{Tea collection agent Requirements}
\begin{itemize}
    \item The system shall allow Tea Collection Agents to search delivery requests
    \item The system shall allow Tea Collection Agents to record the weight of collected tea leaves.
    \item The system shall enable tea collection agents to keep photographic evidence verifying that tea leaves have been successfully collected from the Tea Estate Manager.
    \item The system shall allow the Tea Collection Agent to capture the estate owner's on-device confirmation of collected weight at the point of collection.
    \item The system shall allow the Tea Collection Agent to create a manual collection record for pickups arranged directly with the estate owner outside the app.  
\end{itemize}

\subsubsection{Tea Receiving Officer Requirements}
\begin{itemize}
    \item The system shall allow Tea Receiving Officers to send a tea leaves received confirmation notification to the Factory Officer.
    \item The system shall allow Tea Receiving Officers to submit complaint reports to tea estate owners and factory administrators in the event of tea leaf weight mismatches.
    \item The system shall allow the Tea Receiving Officer to assign a tea grade (Super or Normal) to each received collection. 
    \item The system shall allow the Tea Receiving Officer to compare factory weight against collected weight and flag mismatches per the existing complaint workflow.
\end{itemize}

\subsubsection{Factory Administrator Requirements}
\begin{itemize}
    \item The system shall allow Factory Administrators to register the factory in the system.
    \item The system shall allow Factory Administrators to customize role-based privileges or use the default role-based privileges.
    \item The system shall allow Factory Administrators to manage employees in the system.
    \item The system shall allow Factory Administrators to add other beneficiary items (e.g., Food, Rice, etc.).
\end{itemize}

\subsubsection{Factory Officer Requirements}
\begin{itemize}
    \item The system shall allow Factory Officers to create monthly payments made to Tea Estate Owners.
    \item The system shall allow Factory Officers to manage fertilizer requests, approvals, dispatch details, and payment deductions.
    \item The system shall allow Factory Officers to manage beneficiary items (e.g. Rice etc) requests, approvals, dispatch details, and payment deductions.
    \item The system shall allow Factory Officers to enter daily tea plucking details.
    \item The system shall allow Factory Officers to enter daily attendance into the system.
    \item The system shall allow Factory Officers to enter daily expenses into the system.
    \item The system shall calculate net payable amount as gross revenue less transport cost, fertilizer deductions, and advance payments. 
    \item The system shall allow Factory Officers to record employee salary advance requests and approvals.
    \item The system shall generate a bank-ready payment file (estate owner or employee, bank account, transfer amount) in Excel, CSV, or PDF format. 
    \item The system shall calculate gross revenue as the sum of each tea grade's collected weight multiplied by its configured rate. 
    \item The system shall calculate transport cost per estate, excluding self-delivered collections. 
\end{itemize}

\subsubsection{Factory Manager Requirements}
\begin{itemize}
    \item The system shall allow Factory Managers to view daily and monthly reports.
    \item The system shall allow Factory Managers to analyze charts and graphs.
    \item The system shall allow factory Managers to view the stock and status of Fertlizers.
    \item The system shall allow Factory Managers to view the stock and status of beneficiary items.
    \item The system shall allow Factory Managers to receive complaint reports submitted by Tea Receiving Officers.
\end{itemize}

\subsubsection{Reporting Requirements}
\begin{itemize}
    \item The system shall generate daily tea collection reports.
    \item The system shall generate monthly payment reports.
    \item The system shall generate fertilizer supply and distribution reports.
    \item The system shall generate beneficiary items supply and distribution reports.
    \item The system shall generate employee performance reports.
    \item The system shall allow reports to be exported in digital formats.
\end{itemize}

\subsubsection{Notification Requirements}
\begin{itemize}
    \item The system shall send delivery confirmation notifications to Tea Estate Owners.
    \item The system shall send notifications regarding complaint reports and delivery issues.
    \item The system shall send notifications regarding fertilizer request approvals or rejections.
    \item The system shall notify relevant users regarding monthly payment updates and deductions.
    \item The system shall send notifications to Tea Estate Owners and Factory Administrators confirming that tea leaves have been successfully collected.
    \item The system shall notify Tea Estate Owners and Factory Officers after deliveries are successfully confirmed and finalized by the Tea Receiving Officer.
    \item The system shall notify Factory Managers when a fertilizer item's expiration date is approaching.
    \item The system shall notify Factory Managers when the expiration date of a beneficiary item is approaching.
\end{itemize}

\subsection{Quality Attributes}
\begin{itemize}
    \item \textbf{Security:} The system shall ensure secure authentication using JWT, role-based access control, and protection of sensitive user and financial data.
    \item \textbf{Availability:} The system shall remain available during operational hours, with minimal downtime for factory and estate operations.
    \item \textbf{Modifiability:} The system shall be designed with a modular architecture to allow easy expansion to additional agricultural sectors or business processes.
    \item \textbf{Performance:} The system shall process requests and generate reports with minimal latency, even under high user load.
    \item \textbf{Testability:} The system shall follow a modular architecture with unit, integration, and end-to-end tests to ensure reliability of individual components and workflows.
    \item \textbf{Usability:} The system shall provide a simple, intuitive, and user-friendly interface accessible to users with varying levels of technical expertise.
    \item \textbf{Scalability:} The system shall be able to handle an increasing number of users, estates, and factories without significant degradation in performance.
    \item \textbf{Reliability:} The system shall ensure consistent and accurate data processing, particularly for tea collection records and payment calculations.
    \item \textbf{Offline Compatibility:} The mobile application shall support offline data entry using SQLite, with synchronization to the central database once connectivity is restored.
\end{itemize}
