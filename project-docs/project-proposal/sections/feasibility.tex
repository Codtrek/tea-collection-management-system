\section{Project Feasibility}
\label{sec:feasibility}

\subsection{Technical Feasibility}
\begin{itemize}
    \item \textbf{IDEs:} Visual Studio Code, Android Studio
    \item \textbf{Tools \& Utilities:} GitHub, Postman, Figma, MySQL Workbench
    \item \textbf{Hardware:} Android smartphones, Development laptops/desktops, Cloud hosting server
\end{itemize}

\subsection{Operational Feasibility}
The system is designed with a simple interface to support farmers and collectors who may not be highly familiar with technology.

\subsection{Legal \& Ethical Feasibility}
The system will protect user data and maintain secure access to records.

\subsection{Social Feasibility}
The project supports digital transformation in the agriculture sector and improves operational efficiency.

\subsection{Economic Feasibility}
The system reduces paperwork and improves operational efficiency, which can reduce management costs in the long term.

\subsection{Schedule Feasibility}
The MVP version can be developed within the allocated academic project timeline.
