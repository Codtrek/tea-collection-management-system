\section{Deliverables of the Project}
\label{sec:deliverables}

\subsection{System Deliverables}
The proposed Tea Leaf Collection and Distribution Management System will include the following system components:
\begin{itemize}
    \item Mobile application for tea estate owners, managers, collection agents, and receiving officers
    \item Backend API system developed using Node.js and NestJS
    \item PostgreSQL database management system
    \item Authentication and role-based access control system
    \item Tea collection, delivery, and OTP-based weight verification modules
    \item Complaint handling and delivery confirmation workflows
    \item Fertilizer request, approval, borrowing, and transport tracking module
    \item Monthly payment management and deduction handling module
    \item Reporting and notification module for operational and financial updates
\end{itemize}

\subsection{Documentation}
The project documentation will include:
\begin{itemize}
    \item Project proposal document
    \item Software Requirements Specification (SRS) document
    \item System design documentation
    \item Database design documentation
    \item API documentation
    \item Testing and evaluation reports
    \item User manual and operational guidelines
    \item Final project report
\end{itemize}

\subsection{Project Artifacts}
The following project artifacts will be produced during development:
\begin{itemize}
    \item Source code repository using GitHub
    \item UI/UX designs created using Figma
    \item Database schema and ER diagrams
    \item System architecture diagrams
    \item API collection and testing files (Postman)
    \item Test cases and validation records
\end{itemize}

\subsection{Versioned Deliverables}
The project will be developed in multiple stages:
\begin{itemize}
    \item \textbf{MVP Version}
    \begin{itemize}
        \item Basic user authentication
        \item Tea collection recording and delivery requests
        \item OTP-based weight verification
        \item Basic reporting and notifications
    \end{itemize}
    \item \textbf{Beta Version}
    \begin{itemize}
        \item Fertilizer request and approval workflow
        \item Payment calculation and deduction handling
        \item Complaint management and delivery confirmations
        \item Enhanced reporting and dashboards
    \end{itemize}
    \item \textbf{Final Version}
    \begin{itemize}
        \item Fully integrated management system
        \item Optimized UI/UX
        \item Secure role-based access control
        \item Final testing and deployment
        \item Complete documentation and reporting
    \end{itemize}
\end{itemize}
